# Riverside College

Riverside College is a small campus on the river bend. Mornings begin in classrooms, afternoons open onto the lawns, and teachers stay with a student from the first week through the last exam.

The campus address is 12 River Bend Road, Kochi, Kerala 682016. The front office phone is +91 484 250 1100. The office email is office@riverside.academy.

# Admissions

Applications for 2026-27 are open until 30 November 2026. Bring the qualifying mark sheet, a photo, and a parent contact. Families are welcome to walk the campus on weekday mornings.

An application from the website does not create a login or a roll number. The office reviews the application, then enrolls the student.

The current academic year is 2026-27. It runs from 15 June 2026 to 14 May 2027.

# Departments

Computer Science, code CSE. Programming, systems, and the software studio beside the library.

Electronics, code ECE. Circuits, signals, and the afternoon lab on the first floor.

Mechanical Engineering, code ME. Workshops, design drawing, and the machine hall behind the quad.

Civil Engineering, code CE. Structures, surveying, and the site lab.

# Courses

B.Tech Computer Science, code BT-CSE, is an eight-semester course in Computer Science. Four years of computing, with a studio project in the final year. First-semester subjects include Programming Fundamentals (CSE101, 4 credits) and Discrete Mathematics (CSE102, 3 credits).

B.Tech Electronics, code BT-ECE, is an eight-semester course in Electronics. Devices, communication, and a lab course in every semester. Circuit Theory (ECE101, 4 credits) is a first-semester subject.

B.Tech Mechanical, code BT-ME, is an eight-semester course in Mechanical Engineering. Design, thermal systems, and workshop practice from the first year. Engineering Mechanics (ME201, 4 credits) is taught in semester 3.
